# TeamBook — блокнот руководителя

Персональный самохостинговый блокнот руководителя для ведения заметок о подчинённых: карточки сотрудников, справочники должностей и отделов, история смены должности и зарплаты, полугодовые записи (цели, предложения, пожелания, комментарии, отзывы коллег) и итоги встреч 1-на-1.

Данные хранятся локально в SQLite (на вашем сервере) — ничего не уходит наружу. Доступ защищён входом по паролю. Встроена резервная копия: экспорт и восстановление базы через браузер.

---

## Возможности

**Сотрудники**
- Карточка сотрудника: имя, должность, отдел, зарплата, дата приёма на работу
- История изменений должности и зарплаты по датам (таймлайн)
- Общие заметки о сотруднике (вне привязки к полугодию)
- Кликабельные имена в списке, поиск по имени и фамилии

**Справочники**
- Должности и отделы: создание, переименование, удаление
- Выбор должности/отдела из выпадающего списка при создании и редактировании сотрудника

**Записи по годам**
- Разбивка данных по годам: годы создаются вручную (кнопка «Создать год»), каждый можно и удалить
- Полугодовые записи (I и II полугодие): цели сотрудника, мои предложения, его пожелания, комментарии, отзывы коллег
- Поля полугодий — столбиком сверху вниз

**Встречи 1-на-1**
- Отдельная секция в карточке сотрудника: дата, итоги встречи, правка, удаление

**Дашборд**
- Фильтрация сотрудников по отделу и должности
- Поиск сотрудников по имени и фамилии (регистронезависимо)
- Кликабельные имена — без лишних кликов

**Резервное копирование**
- Экспорт полной копии базы одним файлом (скачивание через браузер)
- Восстановление из файла через загрузку (с проверкой целостности и авто-бэкапом текущей БД)

**Отчёт (Excel)**
- Выгрузка по всем сотрудникам за выбранный год: карточка + I/II полугодие (цели, предложения, пожелания, комментарии, отзывы коллег)
- Выгрузка по одному сотруднику с его карточки (плюс отдельный лист «Встречи 1-на-1»)

**Интерфейс**
- Тёмная аккуратная тема, адаптивная вёрстка
- Сворачиваемые блоки (спойлеры), состояние запоминается в браузере
- Полностью на русском языке

## Быстрый старт (Docker)

Требуется: **Docker + Docker Compose** (входит в Docker Desktop / Docker Engine).

### Шаг 1 — файл `.env`

Создайте файл `.env` рядом с `docker-compose.yml`:

```bash
# Пароль для входа в приложение (обязательно)
HR_PASSWORD=мой_надёжный_пароль
# Секретный ключ сессий — любая длинная случайная строка
HR_SECRET_KEY=$(openssl rand -hex 24)
```

### Шаг 2 — `docker-compose.yml`

Создайте файл `docker-compose.yml`:

```yaml
services:
  teambook:
    image: ghcr.io/shoonia69/teambook:latest
    container_name: teambook
    restart: unless-stopped
    environment:
      - HR_PASSWORD=${HR_PASSWORD:?задайте HR_PASSWORD в .env}
      - HR_SECRET_KEY=${HR_SECRET_KEY:?задайте HR_SECRET_KEY в .env}
    volumes:
      - teambook_data:/app/data
    ports:
      - "5500:5000"

volumes:
  teambook_data:
```

### Шаг 3 — запуск

```bash
docker compose up -d
```

Приложение поднимется на **http://localhost:5500**. Вход — по паролю из `HR_PASSWORD`.

> ⚠️ Секреты (`HR_PASSWORD`, `HR_SECRET_KEY`) подставляются из `.env`, а не хранятся в самом compose-файле — не коммитьте `.env` в репозиторий.

### Без Compose (просто Docker)

```bash
docker pull ghcr.io/shoonia69/teambook:latest
docker run -d --name teambook \
  -p 5500:5000 \
  -e HR_PASSWORD=мой_пароль \
  -e HR_SECRET_KEY=мой_ключ \
  -v teambook_data:/app/data \
  ghcr.io/shoonia69/teambook:latest
```

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `HR_PASSWORD` | да | Пароль для входа в приложение |
| `HR_SECRET_KEY` | рекомендована | Секретный ключ для подписи сессий |
| `HR_DATA_DIR` | нет | Каталог хранения БД (по умолчанию `/app/data`) |
| `PORT` | нет | Внутренний порт приложения (по умолчанию 5000) |

## Хранение данных и резервная копия

- Все данные — в одном файле SQLite (`/app/data/hr_notes.db`).
- В `docker-compose.yml` объявлен named volume `teambook_data`, поэтому **данные переживают пересоздание контейнера**.
- Из интерфейса: страница «Резервная копия» — скачать БД одним файлом или восстановить из файла.
- Из консоли бэкап — просто скопировать файл: `docker cp teambook:/app/data/hr_notes.db ./`

---

## Перенос на другой сервер

1. Старый сервер: откройте «Резервная копия» → «Скачать копию БД» (или `docker cp`).
2. Новый сервер: тот же `docker-compose.yml` + `.env`.
3. Запустите `docker compose up -d`.
4. Восстановите базу: «Резервная копия» → «Восстановить из файла».
