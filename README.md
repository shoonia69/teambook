# TeamBook — блокнот руководителя

Персональный самохостинговый блокнот руководителя для ведения заметок о подчинённых: карточки сотрудников, история смены должности и зарплаты, полугодовые записи (цели, предложения, пожелания, комментарии) и итоги встреч 1-на-1.

Данные хранятся локально в SQLite (на вашем сервере) — ничего не уходит наружу. Экранирование входом по паролю.

---

## Возможности

**Сотрудники**
- Карточка сотрудника: имя, должность, отдел, зарплата, дата приёма на работу
- История изменений должности и зарплаты по датам (таймлайн)
- Общие заметки о сотруднике (вне привязки к полугодию)

**Справочники**
- Должности и отделы: создание, переименование, удаление
- Выбор должности/отдела из выпадающего списка при создании и редактировании сотрудника

**Записи по годам**
- Разбивка всех данных по годам (вкладки на дашборде и в карточке)
- Полугодовые записи (I и II полугодие): цели сотрудника, мои предложения, его пожелания, комментарии

**Встречи 1-на-1**
- Отдельная секция в карточке сотрудника: дата, итоги встречи, правка, удаление

**Дашборд**
- Фильтрация сотрудников по отделу и должности
- Отметки о наличии полугодовых записей
- Поиск сотрудников через фильтры

**Интерфейс**
- Тёмная аккуратная тема, адаптивная вёрстка
- Сворачиваемые блоки (спойлеры), состояние запоминается в браузере
- Полностью на русском языке

## Быстрый старт (Docker)

### 1. Подготовка

Требуется: Docker + Docker Compose.

### 2. Настройка

Создайте файл `.env` рядом с `docker-compose.yml`:

```bash
# Пароль для входа в приложение (обязательно)
HR_PASSWORD=мой_надёжный_пароль

# Секретный ключ сессий — любая длинная случайная строка
HR_SECRET_KEY=$(openssl rand -hex 24)   # или придумайте свою
```

> ⚠️ Без `HR_PASSWORD` контейнер сгенерирует временный пароль и выведет его в логи при первом старте.

### 3. Запуск

```bash
docker compose up -d
```

Приложение будет доступно по адресу: **http://localhost:5500**

Вход — по паролю из `HR_PASSWORD`.

### 4. Перенос на свой сервер / другой хост

Образ можно собрать из исходников на любом хосте:

```bash
docker build -t teambook:latest .
docker compose up -d
```

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `HR_PASSWORD` | да | Пароль для входа в приложение |
| `HR_SECRET_KEY` | рекомендована | Секретный ключ для подписи сессий |
| `HR_DATA_DIR` | нет | Каталог хранения БД (по умолчанию `/app/data`) |
| `PORT` | нет | Внутренний порт приложения (по умолчанию 5000) |

---

## Хранение данных

- Все данные — в одном файле SQLite.
- Файл БД — `/app/data/` внутри контейнера. В `docker-compose.yml` объявлен named volume `hr_notes_data`, поэтому **данные переживают пересоздание контейнера**.
- Для бэкапа достаточно скопировать файл БД из volume (например: `docker cp teambook:/app/data/hr_notes.db ./`).

## Разработка (без Docker)

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

export HR_PASSWORD=test
export HR_SECRET_KEY=dev-secret
python app.py                    # http://localhost:5000
```
